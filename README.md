# RNA-Project---Data-205

### Overview 

Hi! I’m a sophomore at Montgomery College majoring in Data Science, and I’m currently completing the Early College Program. I’m working on a project analyzing gene expression data to better understand respiratory illnesses, including COVID-19. My goal is to identify patterns in gene activity that can help classify diseases and reveal key biological differences between COVID-19 and other conditions. Using data analysis techniques, I’m exploring which genes are the most important for classification and whether smaller subsets of data can still accurately predict disease type. This work could help improve how diseases are diagnosed and deepen our understanding of how the body responds to infections. I’m interested in applying these skills in real-world research or data science opportunities.
